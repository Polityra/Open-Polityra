# Licensing guide

This repository uses more than one license category because software, documentation, research
outputs, datasets, and model artifacts are different kinds of works.

## Default licensing map

| Material                               | Intended license / rule            | Notes                                             |
| -------------------------------------- | ---------------------------------- | ------------------------------------------------- |
| Software source code                   | Apache-2.0                         | See the root `LICENSE` file.                      |
| Documentation written for this project | CC BY 4.0                          | Attribute the project and preserve notices.       |
| Research papers and reports            | Explicit license per publication   | Confirm author and publisher rights first.        |
| Third-party datasets                   | Original dataset license and terms | Never assume the repository license applies.      |
| Model weights and external models      | Model-specific license             | Record restrictions in the model card.            |
| Logos, name and trademarks             | Separate trademark policy          | Copyright licenses do not grant trademark rights. |

## Important

The root Apache-2.0 license applies to project software unless a file or directory contains a
different, explicit license notice. It does not relicense third-party materials, data, model
weights, fonts, images, or other assets.

Before accepting contributions, contributors must have the right to submit them under the applicable
project license. Do not copy material from sources whose license or terms are unknown.

This file is a project policy summary, not legal advice. Have the final licensing and contribution
process reviewed before the foundation or other legal entity formally accepts contributions.
