# Product Overview — Open Polityra Platform

## Product Vision

Open Polityra is an independent, open-source research and strategic intelligence platform. It brings together public data, statistical methods, AI-assisted analysis, and collaborative research to help analysts and researchers understand global economic, geopolitical, security, and resilience trends.

## User Roles

| Role | Access Level |
|---|---|
| Public Visitor | View landing page, about, research overview, methodology pages |
| Registered Analyst | Dashboard access, data source browsing, submit analysis requests, view results, export reports |
| Editor | All analyst capabilities + create/edit sources and datasets |
| Admin | Full platform access including user management and audit log review |

## Core Features

1. **Strategic Dashboard**: Overview of monitored indicators, active analyses, key findings across research domains
2. **Economic Analysis**: Macroeconomic indicator tracking and analysis with comparative data tables
3. **Geopolitical Monitoring**: Diplomatic relationship mapping, alliance network analysis, territorial dispute tracking
4. **Security Research**: Threat assessment, capability tracking, vulnerability analysis
5. **Resilience Monitoring**: Economic, social, institutional, and infrastructure resilience indicators
6. **Scenario Modeling**: Construct, compare, and track scenario pathways with editable assumptions
7. **Forecasting**: Quantitative projections with uncertainty intervals across monitored domains
8. **Report Generation**: Research report creation, peer review workflow, export to JSON/PDF
9. **Source Explorer**: Browse, search, and inspect verified data sources with provenance metadata

## Non-Goals

This platform is NOT:
- An autonomous decision-making system
- A classified intelligence collection tool
- A social media or news aggregation service
- A replacement for domain expert analysis — all outputs require human review
