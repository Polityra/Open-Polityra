# Scenario Analysis Guidelines for Open Polityra

## Purpose

Scenario analysis explores how outcomes might differ under different assumptions. Unlike forecasting
(which predicts a most-likely outcome), scenario analysis examines multiple plausible futures. This
document defines the platform's approach to constructing, evaluating, and presenting scenarios.

## Principles

1. **Explicit Assumptions**: Every scenario must state its assumptions clearly and make them
   editable by users.
2. **Plausibility over Probability**: Scenarios are not ranked by likelihood in a vacuum; they are
   structured narratives grounded in available evidence.
3. **Diversity of Perspectives**: Scenario sets should include views from different stakeholder
   groups and analytical frameworks.
4. **Transparency of Method**: The process used to construct each scenario must be documented.

## Scenario Construction Process

1. **Identify key uncertainties**: What are the critical variables that will determine outcomes?
2. **Define driving forces**: What macro trends, structural factors, and potential shocks shape the
   landscape?
3. **Build scenario narratives**: Each narrative combines a coherent set of assumptions into a
   story-like description of a possible future.
4. **Identify trigger indicators**: Early warning signals that suggest one scenario is becoming more
   likely.
5. **Stress-test assumptions**: What evidence would contradict this scenario?

## Scenario Naming Conventions

Each scenario should have:

- A descriptive name (e.g., "Baseline Continuity" or "Disruption and Restructuring")
- A brief summary line (one sentence)
- The key distinguishing assumptions compared to other scenarios in the set
- Estimated time horizon (short-term, medium-term, long-term)

## Evaluation

Scenario sets should be evaluated on:

- Internal coherence of each narrative
- Distinctiveness of each scenario from others in the set
- Plausibility given available evidence
- Actionability (does it inform decision-making?)
- Breadth (does the set cover a reasonable range of outcomes?)
